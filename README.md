## Syntaxes
- `~` -> comment

- `kit` (for kitten) -> creates variable
- `cat` -> creates constants

- `sniff / sniffmore / hiss` -> if / else if / else

- `zoomies / chase` -> while loop / for loop

- `nap / shrug` -> break / continue

- `trick / knock` -> function / return

- `leap / land / paws` -> `try / catch / finally`
